#私有同步

端到端加密的账号体系

不需要注册手机号或邮箱，12 词助记词就是你的账号，创建后妥善保存即可跨设备恢复。 数据经 AES-256-GCM 端到端加密 + Ed25519 签名后，再通过 Nostr 中继或 WebRTC 在线直连同步， 中继只能看到密文；网页版、安卓版、Windows 版使用同一句助记词即可跨端互通。

零服务器更新机制

GitHub Releases 存安装包，GitHub Pages 存元数据，GitHub Actions 自动发布，无需任何云服务器。

客户端如何检查更新？

安卓版 / Windows 版启动后或手动「检查更新」时读取 updates/latest.json，比较 build 号，发现新版后流式下载并校验 SHA-256，再交给系统安装器。

网页版如何更新？

网页版部署在 GitHub Pages，启动后自动读取 updates/latest.json 与本地版本对比，发现新版会提示「发现新版本 · 立即刷新」。

发布流程是怎样的？

推送 v* 标签后，GitHub Actions 自动构建 Android APK、Windows 安装包，上传到 Releases、计算 SHA-256 并回写 latest.json，官网下载按钮随之自动指向新版本。

#常见问题

安装、更新、同步与隐私

安装 APK 提示「未知来源」怎么办？
这是 Android 系统安全机制。请在系统设置中允许「安装未知来源应用」后重试；应用会先校验 SHA-256 再打开安装器。
数据会传到服务器吗？
不会。数据默认只存本机；开启同步后经 AES-256-GCM 端到端加密上传到 Nostr 中继或经 WebRTC 直连传输，中继只能看到密文，且带 Ed25519 签名防篡改。
网页版、安卓版和 Windows 版能互通吗？
可以。三端使用同一套助记词账号与加密算法，同一句助记词即可跨端互相同步数据；好友直连还支持加密作业分享。
需要账号吗？
不需要注册。12 词助记词即账号，创建后妥善保存即可跨设备恢复，丢失无法找回。
下载慢怎么办？
GitHub 在中国大陆可能较慢，可在设置页配置镜像源；网页版也可通过免费 CDN 加速访问。
Windows 安装包会提示 SmartScreen 吗？
未签名 exe 首次运行会有 SmartScreen 提示，这是 Windows 安全机制，选择「仍要运行」即可；绿色版 zip 解压即可用，无此提示。
