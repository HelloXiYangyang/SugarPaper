常见问题

关于安装、更新与隐私

更新如何工作？

应用启动后或手动「检查更新」时读取 GitHub Pages 上的元数据，发现新版本后流式下载并校验 SHA-256，再交给系统安装器完成安装。全程零服务器。

安装 APK 提示「未知来源」怎么办？

这是 Android 系统安全机制。请在系统设置中允许「安装未知来源应用」后重试；下载完成后应用会校验文件完整性再打开安装器。

数据会传到服务器吗？

不会。数据默认只存本机；开启同步后经端到端加密上传到 Nostr 中继或经 WebRTC 直连传输，中继只能看到密文。

需要账号吗？

不需要注册。12 词助记词即账号，创建后妥善保管即可跨设备恢复，丢失无法找回。

下载慢怎么办？

GitHub 在中国大陆可能较慢，可在设置页配置镜像源；网页版也可通过 CDN 加速访问。
