核心功能

以下功能均已在网页版与安卓版实现，详见 README 功能清单

秒级录入

粘贴老师消息自动解析为结构化作业清单；支持 .txt / .md 文件导入、拖拽文本与语音速记（zh-CN）。

截止分级

已逾期 / 今天 / 明天 / 本周 / 长期自动分组，逾期置顶标红并显示逾期天数。

日历与统计

月 / 周视图、考试便签标记、专注分钟角标；进度环 / 柱状 / 饼图 / 折线图、准时率与科目欠账排行，可导出 TXT 或 PNG。

番茄钟专注

番茄钟四档预设 + 9 种白噪音环境、自定义声音上传、主 / 叠加双音轨混音、呼吸引导与今日专注统计。

便签与提醒

便签支持 Markdown、待办清单一键转作业、图片附件；作业截止与便签定时提醒，时间可自定义，本地通知同条只提醒一次。

私密同步

12 词助记词即账号，AES-256-GCM 端到端加密 + Ed25519 签名；Nostr 中继或 WebRTC 直连，网页版与安卓版可跨端互通。

拍照存档

作业可附最多 4 张图片（自动压缩至最长边 512px，仅存本机），卡片缩略图 + 点击查看大图。

教师与家庭模式

教师模式一键生成标准作业文本发班级群；家庭模式成员档案切换与打卡任务家长确认。

更新机制

零服务器：GitHub Releases 存安装包，GitHub Pages 存元数据，GitHub Actions 自动发布

客户端如何检查更新？

安卓版启动后或手动「检查更新」时读取 updates/latest.json，比较 build 号，发现新版后流式下载并校验 SHA-256，再交给系统安装器。

网页版如何更新？

网页版部署在 GitHub Pages，启动后自动读取 updates/latest.json 与本地版本对比，发现新版会提示「发现新版本 · 立即刷新」；也可以在「我的 → 更新」里手动检查并一键刷新。

发布流程是怎样的？

推送 v* 标签后，GitHub Actions 自动构建 Android APK、上传到 Releases、计算 SHA-256 并回写 latest.json，官网下载按钮随之自动指向新版本。

常见问题

关于安装、更新、同步与隐私

安装 APK 提示「未知来源」怎么办？

这是 Android 系统安全机制。请在系统设置中允许「安装未知来源应用」后重试；应用会先校验 SHA-256 再打开安装器。

数据会传到服务器吗？

不会。数据默认只存本机；开启同步后经 AES-256-GCM 端到端加密上传到 Nostr 中继或经 WebRTC 直连传输，中继只能看到密文，且带 Ed25519 签名防篡改。

网页版和安卓版能互通吗？

可以。两端使用同一套助记词账号与加密算法（v0.26.1 起完成跨端互通修复），同一句助记词即可互相同步数据。

需要账号吗？

不需要注册。12 词助记词即账号，创建后妥善保管即可跨设备恢复，丢失无法找回。

下载慢怎么办？

GitHub 在中国大陆可能较慢，可在设置页配置镜像源；网页版也可通过免费 CDN 加速访问。
