零服务器时代的更新、备份与安全

作者：HelloXiYangyang 最后更新：2026-08-08

零服务器自动更新

糖纸的自动更新不需要任何自建服务器：GitHub Releases 存放安装包， GitHub Pages 存放 updates/latest.json 元数据， GitHub Actions 在发布时自动构建并上传。

  • 安卓版 / Windows 版：启动后或手动「检查更新」时读取 latest.json，比较 build 号，发现新版后流式下载并校验 SHA-256，再交给系统安装器；
  • 网页版：启动后自动对比版本号，发现新版提示「发现新版本 · 立即刷新」；Service Worker 会后台预缓存新版，点「立即升级」秒级生效。

版本发布流程

仓库遵循「即做即更」规则：小功能 / 修复即升小版本发布，重要功能升大版本，禁止攒批。发布流程：

  1. 推送 v* 标签到 GitHub；
  2. GitHub Actions 自动构建 Android APK 与 Windows 桌面版安装包；
  3. 上传到 Releases，计算 SHA-256 并回写 updates/latest.json；
  4. 官网下载按钮与各端自动更新随之指向新版本。
注意 如果发布工作流运行失败，需要手动同步一次 updates/latest.json，否则官网下载按钮会停留在旧版本（曾因此出现安卓版下载不到最新包的问题）。

备份与恢复

数据默认只存本机。建议定期在「设置 → 备份」中导出 JSON 备份（超 7 天未导出时首页会提示）。 恢复时在同一位置导入即可；开启同步后，同一句助记词在任意设备登录也能恢复全部数据。

镜像源与下载加速

GitHub 在中国大陆访问可能较慢。可以在设置页配置镜像源加速下载；网页版也通过免费 CDN 加速访问。 所有安装包均校验 SHA-256，请务必从官网或仓库 Releases 官方渠道获取。

隐私与加密模型

环节方案
账号12 词助记词（PBKDF2 → Ed25519），无需注册
静态数据默认仅存本机（IndexedDB / 本地文件）
同步传输AES-256-GCM 端到端加密 + Ed25519 签名防篡改
传输通道Nostr 中继（只转发密文）或 WebRTC 点对点直连
好友消息预共享密钥 + AES-256-GCM，经 Nostr 中继转发密文

产品红线：不做自建服务器、账号等于本地密钥、数据默认离线优先。完整说明见用户协议与隐私政策。

常见问题

  • 安装 APK 提示「未知来源」？ 这是 Android 系统安全机制，请在系统设置中允许「安装未知来源应用」后重试；应用会先校验 SHA-256 再打开安装器。
  • Windows 安装包提示 SmartScreen？ 未签名 exe 首次运行会有 SmartScreen 提示，选择「仍要运行」即可；绿色版 zip 解压即用，无此提示。
  • 数据会传到服务器吗？ 不会。默认只存本机；同步时中继只能看到密文。
  • 网页版、安卓版和 Windows 版能互通吗？ 可以，同一句助记词即可互相同步。
  • 助记词丢了怎么办？ 助记词即账号，丢失无法找回，请务必妥善保管。
