项目结构

仓库采用「单一 README · 多版本分区」管理，包含以下主要目录：

目录说明
web/网页版（PWA）：原生 HTML5 + CSS3 + JavaScript，零构建、零依赖
app/Flutter 多平台工程：一套代码编译至 Android / Windows
site/官网（本网站）与文档站源码
updates/更新元数据 latest.json（供客户端自动更新）
.github/workflows/Pages 部署与版本发布流水线

技术栈

版本技术路线
网页版原生 HTML5 + CSS3 + JavaScript（零构建、零依赖）
安卓 / WindowsFlutter（共享 app/lib/ 核心代码）
加密同步PBKDF2 → Ed25519，AES-256-GCM 端到端加密 + 签名
传输Nostr 中继（密文转发）+ WebRTC DataChannel（P2P 直连）
测试网页版：node 单元测试 + Playwright e2e；Flutter：flutter_test

本地运行与构建

网页版（零依赖）

# 方式一：直接用浏览器打开
web/index.html

# 方式二：本地静态服务
node web/serve.js 8080
# 打开 http://localhost:8080

Flutter 版（安卓 / Windows）

# 环境要求：Flutter 3.22+、JDK 17、Android SDK
cd app
flutter pub get
flutter test                 # 单元测试
flutter build apk --release  # 正式包
flutter build windows        # Windows 桌面版

APK 输出：app/build/app/outputs/flutter-apk/app-release.apk。Windows 安装包可用 app/build_installer_windows.ps1 配合 Inno Setup 生成。

运行测试

node web/test/unit.test.js          # 解析器 + 统计引擎单元测试
node web/test/e2e.test.js           # 端到端交互测试（需本机 Edge/Chrome + Playwright）
node web/test/screenshot.js         # 生成多断点界面截图
node web/test/verify_docs.js        # 文档同步校验（16 科 + 头像三方一致）

目录结构（Flutter）

app/
├── lib/                          # ★ 共享核心代码（各平台版本共用）
│   ├── main.dart                 # 入口 + 主题 + 帧率检测
│   ├── core/                     # 主题 Token / 矢量图标 / 动画常量
│   ├── models/                   # Task / SubjectConfig / Note / FocusSession
│   ├── data/                     # 解析引擎 / 统计引擎 / 本地存储 / 白噪音合成
│   └── ui/                       # 首页 / 日历 / 统计 / 便签 / 专注 / 设置
├── android/                      # 安卓版平台目录
├── windows/                      # Windows 版平台目录
├── assets/avatar-default.jpg     # 默认头像
└── pubspec.yaml                  # 依赖与资源声明

架构说明

糖纸坚持离线优先：数据默认只存本机，账号 = 本地密钥（12 词助记词）， 不做自建服务器，也不引入社交 / 排行榜。同步时数据在本地完成端到端加密，中继只转发密文； 两台在线设备之间则通过 WebRTC 建立点对点直连，信令经中继交换后即脱离服务器。

参考 更完整的零服务器发布 / 自动更新 / 官网方案见仓库根目录《零服务器多平台发布 · 自动更新 · 官网方案 v2.0》。
