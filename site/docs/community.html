GitHub 仓库

糖纸完全开源（GNU AGPL-3.0），源码托管在 github.com/HelloXiYangyang/SugarPaper。 您可以 Star 支持项目，或在 Releases 页面下载安装包。

反馈问题

使用中遇到问题，欢迎到 Issues 提交反馈。反馈时请尽量提供：平台与版本号、操作步骤、期望行为与实际表现、截图或录屏，这样能帮助我们更快定位问题。

参与贡献

任何形式的贡献都欢迎：

  • 提交 Issue 报告 Bug 或建议新功能；
  • 发起 Pull Request 修复问题、改进交互、优化性能；
  • 完善本文档与官网内容；
  • 帮助翻译或推广糖纸。

开发相关说明见开发文档，版本管理规则见仓库 README。

协议与隐私

  • 用户协议
  • 隐私政策
  • 应用内也可在「我的 → 法律与隐私」随时查看这两份协议。

更新日志

完整更新日志按版本收录在 README 版本更新日志 中，官网首页的「更新日志」区会自动读取 updates/latest.json 展示最新版本内容。
