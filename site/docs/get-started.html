快速上手

从零开始的糖纸之旅

作者：HelloXiYangyang 最后更新：2026-08-08
提示 本部分教程适用于第一次接触糖纸、对作业管理应用了解不多的用户。如果您已经熟悉同类工具，可以直接跳到应用帮助。

欢迎来到从零开始的糖纸之旅！糖纸是一款适用于小初高学生的多平台作业管理助手，可以一目了然地管理每天的作业。 在本系列教程中，每当您看见 👉 符号，就说明您应该做一些事情，其余内容仅供您参考和更深入的理解。

下载与安装

糖纸目前提供以下平台版本：

平台状态说明
Android✅ 可下载APK 安装包，Android 7.0+
Web PWA✅ 在线可用零安装，可离线使用，可安装到桌面
Windows✅ 可下载setup.exe 安装包 / 绿色版 zip，Windows 10+
鸿蒙 / 小程序⬜ 规划中主流道分别为 AppGallery 与微信平台
去下载 👉 前往下载页，选择适合您的平台开始下载。官网下载按钮会自动指向最新版本并校验 SHA-256。

首次启动：同意协议

首次打开糖纸时，必须阅读并勾选同意《用户协议》和《隐私政策》后才能进入使用（不同意则无法进入）。 协议内容随时可以在「我的 → 法律与隐私」中查看。

创建账号：12 词助记词

糖纸不需要注册。进入应用后创建一个「12 词助记词」即完成注册： 助记词经 PBKDF2 派生密钥、Ed25519 签名，配合 AES-256-GCM 端到端加密，账号与数据完全由您自己掌握。

重要 助记词只在创建时完整展示一次，请妥善抄写保存。助记词就是账号本身，丢失后无法找回，任何持有助记词的人都能恢复您的数据。

秒级录入第一条作业

糖纸的录入设计目标是「粘贴即用」：

  • 粘贴文本：把老师在班级群里发的作业消息粘贴进来，自动解析为结构化作业清单（支持中文数字编号、打卡/背诵任务自动分类）；
  • 文件导入：支持 .txt / .md 文件导入，也可以直接把文本拖进窗口；
  • 语音速记：说作业、说通知，自动转成文字（Web Speech API · zh-CN）；
  • 教师格式：老师使用「教师模式」生成的标准格式文本，学生粘贴即可秒级导入。

👉 打开糖纸首页，粘贴老师发的第一条作业消息，体验自动解析。

完成作业与截止管理

录入后，作业会按已逾期 / 今天 / 明天 / 本周 / 长期自动分组，逾期置顶标红并显示逾期天数。 点击「完成」自动置底，进度一目了然；误操作可随时撤销，也可以设置优先级、日期并拖拽排期。

跨设备同步

在另一台设备上用同一句助记词登录，即可恢复并同步全部数据： 数据经 AES-256-GCM 端到端加密后通过 Nostr 中继传输，中继只能看到密文； 当两台设备同时在线时，会建立 WebRTC 点对点直连，直接互传加密快照，不经过任何服务器。
