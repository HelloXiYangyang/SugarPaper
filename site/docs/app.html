糖纸全部功能的使用说明

作者：HelloXiYangyang 最后更新：2026-08-08

首页与作业列表

首页集中展示今日概览（进度环、连胜、XP）与全部作业。作业按已逾期 / 今天 / 明天 / 本周 / 长期自动分组， 逾期置顶标红并显示逾期天数。支持关键词搜索、科目筛选、优先级筛选，点击「完成」自动置底并可撤销。

  • 快捷规划：新建作业时可选「今天 / 明天 / 后天 / 本周内 / 下周 / 长期」，默认当日；
  • 拖拽排期：桌面 / 平板端支持拖拽调整日期与顺序；
  • 图片附件：任务可附最多 4 张图片，卡片显示缩略图。

日历与统计

日历视图支持月 / 周切换，考试安排便签会注入日历并标记显示，日期格上还有专注分钟角标。 统计页提供整体进度环、每日完成趋势柱状图、科目分布饼图与历史趋势折线图，并可按科目查看准时完成率与欠账排行，报告可导出 TXT 或 PNG。

  • 考试标记：考试 / 测验 / 期末类便签在日期格显示「考」；
  • 报告卡片：一键生成 640×880 的学期报告（进度环 / 摘要 / 科目分布 / 欠账排行 / 每日趋势 / 专注统计）并分享或打印。

番茄专注与白噪音

任务卡一键开始专注，支持四档番茄钟预设与 9 种白噪音环境（白噪音、粉红噪音、棕噪音、雨声、篝火、图书馆等，由 Web Audio 实时合成）。 支持主音量 / 叠加音量双音轨混音、自定义声音上传（本地音频 ≤2MB）、呼吸引导与今日专注统计；专注页还有独立的一级 Tab 与场景渐变氛围。

便签与提醒

便签支持 Markdown 排版与编辑 / 预览切换、置顶 / 归档 / 颜色 / 标签、图片附件与语音速记； - [ ] 待办清单可一键转为作业。作业截止与便签均支持定时提醒（前一晚与当天早上时间可自定义），本地通知同一条只提醒一次。

提醒范围 Android 8.0+ 自动适配系统通知渠道；Windows 桌面版使用原生 toast；网页版在浏览器允许通知时可用。

拍照存档

作业可附带最多 4 张图片（拍黑板、作业存档），自动压缩至最长边 512px，仅存本机并随加密快照同步；卡片显示缩略图，点击可查看大图。 拖入图片时应用会明确提示 OCR 暂不支持，并引导使用拍照存档。

激励体系

完成作业可获得 XP 与糖果，类型 / 优先级计分、欠账双倍补完；连胜火焰、每日 XP 目标、12 枚成就徽章墙， 完成作业时伴随 XP 飘字与徽章解锁动画，让坚持看得见。每日目标支持轻松 / 标准 / 挑战三档，可在设置页随时调整。

好友直连

与同学通过邀请交换共享密钥后，即可端到端加密互发消息（AES-256-GCM），分享的作业可一键导入（科目 / 标题 / 截止 / 优先级 / 图片完整保留）。 消息经 Nostr 中继转发密文，无中心服务器，好友也只能看到您主动分享的内容。

  • 邀请导入：生成邀请（含共享密钥）/ 复制 / 粘贴导入，对方导入后自动回发 friend-req，双方自动确认；
  • 好友管理：昵称 / 公钥 / 最近消息展示，删除好友即停止接收其事件。

主题与个性化

内置经典白 + 清新蓝绿 / 阳光黄桃 / 玫瑰粉 / 梦幻紫 / 薄荷绿 5 套马卡龙配色 + 暗色，共 7 套主题平行切换， 每套主题配有专属图标主色 / 辅色；内置小初高 16 学科，支持自定义默认头像与图片上传。

教师模式与家庭模式

教师模式：按标准格式排好作业（科目 / 条目 / 截止 / 优先级），一键复制或下载 .txt 发到班级群，学生粘贴进糖纸即可秒级导入。 家庭模式：家庭成员助记词档案一键切换代管，打卡类任务需要家长确认。
