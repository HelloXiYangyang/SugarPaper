# 糖纸 Contracts（业务契约）

各端语言不同，不共享代码，共享本目录的契约与测试向量。

## 目录

```text
contracts/
├── schema/    # 数据模型 JSON Schema（唯一权威定义）
├── protocol/  # 加密协议 / 同步协议 / 好友直连协议说明
└── tests/     # 一致性测试向量（输入 + 期望输出）
```

## 规则

- 任何端（Vue / Kotlin / C# / ArkTS / 小程序）接入 = 实现契约 + 通过全部测试向量 + 通过视觉对拍。
- 数据字段名、默认值、存储键与旧版（`web/js/store.js`、`app/lib`）保持一致，保证用户数据迁移无损。
- 测试向量文件为 JSON，每端用原生测试框架读取并断言。

## 测试向量清单

| 文件 | 覆盖 |
|---|---|
| `tests/xp.json` | XP 计算（类型 / 优先级 / 逾期双倍） |
| `tests/crypto.json` | AES-256-GCM 信封格式与签名验签（向量占位，随各端实现补充） |
