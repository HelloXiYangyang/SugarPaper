# 常见问题

- **安装 APK 提示「未知来源」？**
  这是 Android 系统安全机制，请在系统设置中允许「安装未知来源应用」后重试；应用会先校验 SHA-256 再打开安装器。

- **Windows 安装包提示 SmartScreen？**
  未签名 exe 首次运行会有 SmartScreen 提示，选择「仍要运行」即可；绿色版 zip 解压即用，无此提示。

- **数据会传到服务器吗？**
  不会。默认只存本机；同步时中继只能看到密文。

- **网页版、安卓版和 Windows 版能互通吗？**
  可以，同一句助记词即可互相同步。

- **助记词丢了怎么办？**
  助记词即账号，丢失无法找回，请务必妥善保管。
