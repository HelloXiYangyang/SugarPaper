# 隐私与加密模型

| 环节 | 方案 |
| :--- | :--- |
| 账号 | 12 词助记词（PBKDF2 → Ed25519），无需注册 |
| 静态数据 | 默认仅存本机（IndexedDB / 本地文件） |
| 同步传输 | AES-256-GCM 端到端加密 + Ed25519 签名防篡改 |
| 传输通道 | Nostr 中继（只转发密文）或 WebRTC 点对点直连 |
| 好友消息 | 预共享密钥 + AES-256-GCM，经 Nostr 中继转发密文 |

产品红线：**不做自建服务器、账号等于本地密钥、数据默认离线优先**。
完整说明见[用户协议与隐私政策](../community/legal.md)。
