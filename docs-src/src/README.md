欢迎来到糖纸 · SugarPaper 的文档。

糖纸（`SugarPaper`）是一款面向小学到高中学生的**多平台作业管理助手**，可以一目了然地管理每天的作业。
应用采用**离线优先 + 端到端加密**架构：秒级录入、截止分级、番茄专注、日历统计，学习数据默认只存本机，同步时也全程加密。
名字的灵感，来自「让作业管理像糖果一样甜美简单」这句 slogan。
