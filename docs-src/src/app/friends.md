# 好友直连

与同学通过邀请交换共享密钥后，即可**端到端加密**互发消息（AES-256-GCM）：

- **邀请导入**：生成邀请（含共享密钥）/ 复制 / 粘贴导入，对方导入后自动回发 friend-req，双方自动确认；
- **加密消息**：经 Nostr 中继转发密文（kind 19324），无中心服务器；
- **作业分享**：任务加密分享给好友，对方确认后一键导入（科目 / 标题 / 截止 / 优先级 / 图片完整保留）；
- **好友管理**：昵称 / 公钥 / 最近消息展示，删除好友即停止接收其事件。
