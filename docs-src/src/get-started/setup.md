# 下载与安装

糖纸目前提供以下平台版本：

| 平台 | 状态 | 说明 |
| :--- | :--- | :--- |
| Android | ✅ 可下载 | APK 安装包，Android 7.0+ |
| Web PWA | ✅ 在线可用 | 零安装，可离线使用，可安装到桌面 |
| Windows | ✅ 可下载 | setup.exe 安装包 / 绿色版 zip，Windows 10+ |
| 鸿蒙 / 小程序 | ⬜ 规划中 | 主流道分别为 AppGallery 与微信平台 |

前往[官网下载页](https://helloxiyangyang.github.io/SugarPaper/download/)选择适合您的平台开始下载。
官网按钮会自动读取 `updates/latest.json` 指向最新版本，安装包托管在 GitHub Releases 并校验 SHA-256。

::: tip

GitHub 在中国大陆访问可能较慢，可查看[下载镜像](../management/mirror.md)或配置镜像源。

:::
