# 秒级录入第一条作业

糖纸的录入设计目标是「粘贴即用」：

- **粘贴文本**：把老师在班级群里发的作业消息粘贴进来，自动解析为结构化作业清单（支持中文数字编号、打卡 / 背诵任务自动分类）；
- **文件导入**：支持 `.txt` / `.md` 文件导入，也可以直接把文本拖进窗口；
- **语音速记**：说作业、说通知，自动转成文字（Web Speech API · zh-CN）；
- **教师格式**：老师使用「教师模式」生成的标准格式文本，学生粘贴即可秒级导入。

打开糖纸首页，粘贴老师发的第一条作业消息，体验自动解析。
