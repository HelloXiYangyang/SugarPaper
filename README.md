# 🧁 糖纸 · SugarPaper —— 全平台作业管理助手

> **Slogan**：让作业管理像糖果一样甜美简单。
> **核心理念**：离线优先 · 设备直连 · 马卡龙美学 · 零服务器依赖

---

## 📖 项目简介

糖纸 · SugarPaper 是一款面向小学至大学学生的**全平台作业管理应用**，基于 Flutter 一套代码编译至 iOS、Android、鸿蒙、Windows、macOS、Linux、Web。应用采用**离线优先 + 设备间 P2P 加密直连**架构，学习数据永不落盘到任何服务器，兼顾隐私与多设备同步需求。

**目标用户**：需快速录入作业并追踪进度的学生；在手机/平板/电脑间切换的多设备用户；重视隐私、不愿数据上云的学生和家长。

**核心价值**：
1. **秒级录入**：粘贴老师发的文本，自动解析为结构化作业清单。
2. **一键管理**：点击"完成"自动置底，进度一目了然。
3. **私密同步**：设备间通过局域网或点对点加密直连，数据不经过任何服务器。
4. **视觉治愈**：低饱和马卡龙色系，愉悦的使用体验。
5. **数据洞察**：日历视图和统计图表，让学习进度可视化。

## ✨ 核心特性

- 📝 **文本解析导入**：粘贴老师消息 → 正则解析 → 预览 → 覆盖/追加导入
- ✅ **任务管理**：进行中/已完成分组、完成/撤销动画、软删除、手动排序
- ⏰ **截止分级与逾期置顶**：任务按「已逾期 / 今天 / 明天 / 本周 / 长期」分组，逾期自动置顶标红并显示逾期天数
- 🔍 **搜索与筛选**：关键词搜索 + 科目 Chip 筛选 + 优先级筛选
- 📝 **便签**：轻量速记（考试安排/老师通知/物品清单/回执模板），置顶/归档/颜色/标签/提醒，一键转为作业
- 📅 **日历视图**：月/周切换、截止日期管理、日期格任务点、拖拽排期（桌面/平板）
- 📊 **统计图表**：整体进度环、每日完成趋势柱状图、科目分布饼图、历史趋势折线图
- 🍅 **番茄钟与专注场景**：番茄/倒计时循环、任务卡一键开始专注、完成收获糖果；白/粉红/棕噪音与雨声/篝火/图书馆由 Web Audio 实时合成（零音频文件、离线可用）
- 🔔 **提醒与数据安全网**：作业截止（昨晚 20 点/当天早 7-9 点/逾期即时）与便签提醒；超 7 天未导出备份时首页提示，存储用量可视化
- 🎬 **动态动画**：设置页动画总开关、帧率模式（自动/60/120）+ 流畅度自测、方向感知页面过渡、滚动显现缩放（进入/离开视口从小到大、从大到小）、按压缩放反馈、开关弹簧回弹过渡、饼图转圈加载与扇区绽放、逐项淡入微动画、进度条流光，尊重系统“减弱动态效果”
- 🎨 **矢量图标**：全界面自绘 SVG 图标（导航/按钮/标签/空状态等，24×24 描边风格随主题变色）、默认头像（内置喜羊羊图片）+ 自定义图片上传
- 🔗 **设备绑定**：房间码 + 二维码，mDNS 局域网发现，WebSocket 增量同步
- 🌐 **跨网络同步（可选）**：WebRTC + STUN/TURN 实现不同子网互联
- 📱 **五档响应式布局**：Compact / Medium / Expanded / Large / Extra Large
- 🌙 **个性化**：主题自由切换（经典白 + 清新蓝绿/阳光黄桃/玫瑰粉/梦幻紫/薄荷绿 5 套马卡龙配色 + 暗色，7 套平行）、头像（默认喜羊羊图片 + 自定义上传）、科目管理（内置小学/初中/高中 16 学科）、通知提醒、JSON 导出/导入备份

## 🛠 技术栈

| 组件 | 选型 | 说明 |
| :--- | :--- | :--- |
| 前端框架 | Flutter 3.22+ (Dart 3.4+) | 一套代码编译至全平台 |
| 状态管理 | Riverpod 2.5+ | 任务列表、同步状态、统计状态 |
| 本地数据库 | Hive 4.0+ | 轻量 NoSQL，离线优先存储 |
| 日历视图 | `table_calendar` 3.0+ | 月/周视图 |
| 统计图表 | `fl_chart` 0.68+ | 柱状图、饼图、折线图 |
| 设备发现 | `multicast_dns` / bonjour / nsd / zeroconf | 局域网广播 `_sugarpaper._tcp` |
| P2P 通信 | `shelf` + `web_socket`（dart:io 原生 WebSocket） | 增量变更交换 |
| 跨网穿透（可选） | `flutter_webrtc` + 公共 STUN/TURN | 需用户授权 |
| 二维码 | `qr_flutter` + `mobile_scanner` | 绑定码生成/扫描 |
| 响应式 | `flutter_screenutil` + `LayoutBuilder` + 自定义 `Breakpoint` | 五档断点 |
| 动画 | `implicitly_animated` + `confetti` + `flutter_staggered_animations` | 列表/撒花/过渡 |
| 本地化 | `flutter_localizations` | 中英文 |
| 文件导入导出 | `file_picker` + `path_provider` | JSON 备份 |

**架构原则**：无后端依赖，所有数据交换仅在用户设备间进行，不使用任何云数据库或认证服务。

## 🚀 快速开始（Web 版）

**方式一（零依赖）**：直接用浏览器打开 [`web/index.html`](./web/index.html)。

**方式二（本地服务）**：
```bash
node web/serve.js 8080
# 打开 http://localhost:8080
```

**运行测试**：
```bash
node web/test/unit.test.js          # 解析器 + 统计引擎单元测试
node web/test/e2e.test.js           # 端到端交互测试（需本机 Edge/Chrome + Playwright）
node web/test/screenshot.js         # 生成多断点界面截图至 web/test/shots/
node web/test/verify_docs.js        # 文档同步校验（16 科 + 头像：代码/PRD/README 三方一致）
```

**目录结构**：
```
web/
├── index.html            # 入口（经典脚本加载，file:// 可直接打开）
├── css/
│   ├── theme.css         # 马卡龙主题 Token（浅色/深色）
│   └── app.css           # 布局与组件样式 + 五档断点
├── js/
│   ├── util.js           # 工具函数
│   ├── parser.js         # 文本解析引擎
│   ├── store.js          # 本地存储与状态管理
│   ├── stats.js          # 统计引擎（纯函数，可单测）
│   ├── ui-modals.js      # 弹窗 / 导入 / 编辑 / Toast
│   ├── ui-home.js        # 首页任务列表
│   ├── ui-calendar.js    # 日历视图
│   ├── ui-stats.js       # 统计视图（SVG 图表）
│   ├── ui-settings.js    # 设置页
│   └── app.js            # 应用主控制器
├── test/                 # 单元测试 / 端到端测试 / 截图脚本
├── serve.js              # 极简静态服务器
└── manifest.webmanifest  # PWA 清单
```
